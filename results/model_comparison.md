## 데이터 누수 전후 비교 (CatBoost)

조건이 다른 실험 두 개가 있습니다. **두 실험의 숫자는 서로 비교하지 않습니다.**

| 조건 | 실험 A | 실험 B |
|------|--------|--------|
| 목적 | 최종 모델 기준에서 누수 제거 효과 확인 | 팀 점수 0.950이 높게 나온 이유 확인 |
| 위험 기준 | 폐업률 **중앙값 (2.3%)** — 최종 모델과 같음 | 폐업률 **상위 25% (3.6%)** — 팀 버전과 같음 |
| SMOTE | **사용 안 함** | 전: 나누기 전에 적용 / 후: 학습용에만 적용 |
| CatBoost 설정 | 04 노트북과 같은 기본 설정 | 팀이 찾은 최적 설정 |
| 시드 | 42 | 42, 7 평균 |
| 결과 파일 | `leakage_exp_A_median.json` | `leakage_exp_B_top25.json` |

### 실험 A: 최종 모델과 같은 조건 (중앙값 기준)

| 지표 | 누수 제거 전 | 누수 제거 후 |
|------|:-----------:|:-----------:|
| F1-score | 0.740 | **0.694** |
| ROC-AUC | 0.823 | **0.796** |

- 제거 전: 같은 분기 정보 132개 사용, 랜덤 분할 (시험 7,995행)
- 제거 후: 과거 분기 정보 66개만 사용, 시간 순서 분할 (시험 7,376행)
- **제거 후 값은 04 노트북의 최종 CatBoost(위 표의 `*`)와 같습니다.** 원본 값 0.6944 / 0.7955가 소수점 4자리까지 일치합니다.
- 위험 기준이 중앙값이라 위험·정상이 반반이어서 SMOTE를 쓰지 않습니다. 그래서 이 실험에는 SMOTE 문제가 들어 있지 않습니다.
- 단계별로 보면 AUC 하락은 거의 전부 시간 순서 분할에서 나왔습니다 (중간 단계: F1 0.717 / AUC 0.796).
- 결과 파일에서 M0 = 제거 전, M1 = 중간 단계, M2 = 제거 후입니다. 시드 7, 2024 결과도 같이 들어 있습니다.

### 실험 B: 팀 기준 재현 (상위 25% 기준)

| 지표 | 누수 제거 전 | 누수 제거 후 |
|------|:-----------:|:-----------:|
| F1-score | 0.879 | 0.538 |
| ROC-AUC | 0.950 | 0.806 |

- 제거 전: 같은 분기 정보 사용, SMOTE를 나누기 전에 적용, 랜덤 분할
- 제거 후: 과거 분기 정보만 사용, SMOTE는 학습용에만 적용, 시간 순서 분할
- AUC 하락 0.144 중 약 83%가 SMOTE를 나누기 전에 적용한 것에서 나왔습니다. 팀 점수 0.950이 믿을 수 없었던 주된 이유입니다.
- 결과 파일에서 E0 = 제거 전, E3 = 제거 후입니다. E1, E2는 중간 단계입니다.

F1은 시험 데이터의 위험 비율에 따라 값이 달라집니다. 실험 B의 제거 전에는 가짜 데이터가 섞여 위험이 50%였고, 제거 후에는 실제 비율인 약 26%입니다. 그래서 F1 하락에는 이 비율 차이도 들어 있고, 두 조건을 비교할 때는 ROC-AUC가 더 적합합니다.

**실험 B의 제거 후 값(0.538 / 0.806)은 최종 모델(0.694 / 0.796)과 다릅니다.** 위험 기준과 CatBoost 설정이 다르기 때문이며, 최종 모델과 이어지는 비교는 실험 A입니다.

## 평가 조건

- 위험 기준: 폐업률 중앙값(2.3%) 이상이면 위험(1)
- 분할: 시간 순서대로 Train 70% / Val 10% / Test 20%
- 트리 모델 입력: 과거 분기(t-1, t-2) 기반 66개 피처
- LSTM / GRU 입력: 과거 5개 분기 시퀀스
- 분류 임계값: 0.5

LSTM / GRU는 시퀀스를 만들 때 각 그룹의 첫 5개 분기가 빠져서, 트리 모델과 시험 데이터 행이 완전히 같지는 않습니다.
